# 軽貨物・教育記録サポート (MVP)

本プロジェクトは、軽貨物運送および教育記録を効率化するための検証用Webアプリケーションです。

## 概要
- **目的**: 軽貨物配送の業務記録および教育プロセスのデジタル化による効率化。
- **対象**: ドライバー、管理者、教育担当者。
